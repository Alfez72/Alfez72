## Data analysis

- Exploratory data analysis, SQL querying, data cleaning, outlier and missing-value handling
- Feature engineering, feature selection and dimensionality reduction (PCA)
- Visualization with Matplotlib and Seaborn to find structure, relationships and data-quality issues before modeling

## Machine learning

- Supervised learning: regression and classification with Logistic Regression, KNN, Naive Bayes, Decision Trees, SVM and gradient boosting (XGBoost)
- Unsupervised learning: clustering and dimensionality reduction
- Model evaluation, hyperparameter tuning and systematic comparison against baselines
- End-to-end pipelines: cleaning, feature engineering, tuning and evaluation (Ames Housing regression with a tuned XGBoost model: **RMSE 0.1308, R² 0.9083**)

## Deep learning

- Architecture benchmarking: Perceptron, ANN and CNN compared on MNIST to study how architectural choices, not only depth, drive performance
- Sequence modeling: a SimpleRNN baseline against an LSTM to show the effect of gated memory
- Neural network design, training and evaluation with TensorFlow

## Natural language processing

- Text preprocessing, tokenization and embeddings
- Text and emotion classification (six-class emotion prediction from raw sentences)
- Language modeling and next-word prediction with recurrent architectures
- Transformer-based models and the Hugging Face ecosystem

## Generative AI

- **Retrieval-augmented generation:** document loading, chunking, embedding-model selection (HuggingFace embeddings including KURE-v2), vector indexing in Chroma and FAISS, retrieval, and answer generation grounded in retrieved context with Groq-hosted LLMs
- **Retrieval quality:** evaluating RAG pipelines on retrieval accuracy and latency, and tuning context retrieval to improve both
- **Structured outputs:** function calling and schema-constrained JSON output so model responses can drive deterministic downstream steps
- **Prompt engineering:** instruction design, output formatting and prompt iteration against evaluation results
- **Speech and media pipelines:** media ingestion with yt-dlp, audio chunking, local transcription with OpenAI Whisper, then LLM summarization and structured extraction of action items, key decisions and open questions
- **Conversational interfaces:** RAG chains over transcripts and documents, served through Streamlit
- **LLM providers and SDKs:** Anthropic Claude API, Groq, LangChain

## Agentic AI

- **Workflow design in LangGraph:** typed state schemas, nodes and edges, sequential pipelines, and parallel branches merged with reducers
- **Routing:** conditional edges that classify a query and direct it to the right pipeline (handbook retrieval, fee-structure retrieval or general knowledge), with deterministic routing loops
- **Iterative loops:** tool-use cycles with a reviewer step that evaluates output and sends it back for revision
- **Tool use:** tool and function-calling mechanisms with validated, structured arguments and results
- **Human-in-the-loop:** approval checkpoints that pause a workflow for a person to review or edit before it continues
- **Multi-agent orchestration:** coordinating specialized agents with explicit state management so behavior stays predictable and traceable
- **Frameworks:** LangGraph, LangChain, Anthropic Claude SDK
